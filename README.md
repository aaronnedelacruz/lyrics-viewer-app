# Lyrics Viewer App

A simple Android application built with Kotlin that allows users to browse and view song lyrics through a clean and easy-to-read interface.

> **Note:** *This repository showcases one of my earlier Android projects. While I would approach certain implementation details differently today, I have kept the project unchanged to document my learning progress.*

## Features

* Browse available songs
* View song lyrics in a clean interface
* Simple and user-friendly navigation
* Optimized for readability

## Tech Stack

* Kotlin
* Android Studio
* XML Layouts

## Getting Started

### Prerequisites

* Android Studio
* Android SDK

### Installation

1. Clone the repository.

   ```bash
   git clone https://github.com/your-username/lyrics-viewer-app.git
   ```

2. Open the project in Android Studio.

3. Sync the Gradle files.

4. Build and run the application on an Android emulator or physical device.

## How It Works

1. Launch the application.
2. Select a song from the available list.
3. View the song lyrics on a dedicated screen designed for easy reading.
